# APEX 圈速紀錄網站

這是我這週Vibe Coding作業做的網頁，主要拿來記錄GT7或其他賽車遊戲的單圈成績。

可以自己新增圈速，也可以改掉打錯的資料。上面會顯示最快圈速、平均圈速，旁邊有折線圖可以看成績變化。資料會暫時存在使用的瀏覽器裡。

## 怎麼開

直接用瀏覽器開啟 `index.html` 就可以了，不需要安裝其他東西。

第一次可以先按「載入範例」，看一下圖表和紀錄怎麼顯示。再試著輸入自己的資料，例如圈速 `1:42.386`。

## 這個資料夾裡的東西

- `index.html`：網頁本身，程式都在這個檔案裡。
- `SPEC.md`：我想做的功能和畫面規劃。
- `AI_PROCESS.md`：這次怎麼和AI討論、後來又改了什麼。
- `README.md`：這份說明。

## 目前還沒有的功能

網頁不會連線到GT7自動抓圈速，資料都是自己輸入的。也沒有會員登入和雲端備份。如果清掉瀏覽器的網站資料，紀錄可能會不見，所以有需要的話可以先匯出CSV。
